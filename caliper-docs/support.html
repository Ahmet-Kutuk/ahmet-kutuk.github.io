Help

Theme support

Most answers are already in these docs: press / to search settings, sections and guides. If something is still unclear or broken, send a request below.

You get a confirmation email with your request number right away. Do not include passwords or staff account details.

#Response times

  • First reply within one business day, Monday to Friday. Every request gets an automatic confirmation as soon as it arrives.
  • Bugs in the theme are fixed in the next release. Problems that stop checkout or break a page are answered first.

#What support covers

  • Setting up the theme, presets, sections and blocks.
  • Product data fields, filters and menus as described in these docs.
  • Bugs in Vernier's own code, on the latest version.

#What it does not cover

  • Custom code changes and design work.
  • Problems caused by apps or edited theme files. We help find the cause; the app's developer fixes their part.
  • Store setup outside the theme, such as payments, shipping and taxes.

#Before you write

  1. Update to the latest version of Vernier.
  2. Check whether the problem also happens with your apps turned off, or in an unedited copy of the theme.
  3. Note the page, the steps and what you expected, and take a screenshot.

Important

Never send passwords or staff account details. If we need access to your store, we send a collaborator request that you approve.

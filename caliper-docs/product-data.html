Product data

Caliper turns product details into clear interface: the size as a headline, part numbers you can copy, a specifications table, compatibility you can check. These details live in metafields. The theme works without them, but they are what make a technical catalog fast to shop.

#How to add a field

  1. Open SettingsCustom dataProducts (or Variants or Collections for those fields).
  2. Select Add definition and enter the name.
  3. In Namespace and key, type the value from the tables below exactly, for example caliper.size.
  4. Pick the Type from the table. For list types, choose List of values.
  5. Select Save. Fill the field on each product under Metafields at the bottom of the product page in the admin, or for many products at once with the bulk editor or a CSV import.

Important

The namespace and key must match exactly, including the dot and the underscore. A field named caliper.Size or size is not read.

#Key features

The Key features block shows up to six rows with an icon, a title and a short line. Add it to the product template, then click the connect icon beside each title and line and pick a product metafield, so every product shows its own features. A row is hidden on products where its title is empty.

#Writing specifications

One line per specification, with the label, a colon and the value. Caliper lines them up in a table and uses the labels to compare products side by side.

Material: Stainless steel 304
Drive: Torx T25
Head: Flat, 82°
Thread: Coarse

#Questions and answers

  1. Open SettingsCustom dataMetaobjects and select Add definition.
  2. Name it Q and A and add two fields: question (Single line text) and answer (Rich text or Multi-line text).
  3. Add a product definition caliper.questions with the type Metaobject, pick Q and A and choose List of entries.
  4. On a product, add entries under Questions and answers. They show in the Questions and answers block, with an "Ask a question" form below.

#Feature scores

Enter the scores as JSON, one name and number per pair. The top score is set in the block (5 by default).

{"Durability": 4, "Ease of install": 5, "Corrosion resistance": 5}

#Sizes without a size field

If your sizes are variant options (for example Length), turn on Theme settingsProduct cardsUse variant options as the size. Caliper then builds the headline from the option values.

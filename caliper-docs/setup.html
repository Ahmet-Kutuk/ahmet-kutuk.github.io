Get started

Set up the demo look in 10 minutes

Follow these steps in order. Each one names the exact place in the Shopify admin. At the end your store looks and works like the demo for your preset.

#1. Pick a preset

  1. Open Online StoreThemes and select Customize on Caliper.
  2. Open Theme settings, select Change theme style at the top and pick Caliper, Gauge or Foundry, then Save.

#2. Create the product data fields

Caliper reads product details from metafields. Create them once; every product then has a place for its size, pack, specifications and more.

  1. Open SettingsCustom dataProducts.
  2. Select Add definition.
  3. Enter the Name, then select the namespace and key field and type the value from the table below (for example caliper.size).
  4. Choose the Type from the table and select Save.
  5. Repeat for each field you need.
NameNamespace and keyTypeNeeded for
Sizecaliper.sizeSingle line textThe big size on cards and product pages
Size notecaliper.size_noteSingle line textThe small note beside the size, such as T25
Packcaliper.packSingle line textPack size on cards, such as Box of 100
Manufacturer part numbercaliper.mpnSingle line textThe MPN chip on the product page
Specificationscaliper.specsMulti-line textThe specifications table
Compatibilitycaliper.fitmentList of single line textCompatibility list and vehicle finder
Documentscaliper.documentsList of filesData sheets with preview

Tip

The sample content pack includes metafield-definitions.json with every field and its exact type, including the optional ones. See Product data for the full list.

#3. Import the sample products (optional)

  1. Download the sample content pack and unzip it.
  2. Open ProductsImport and choose the CSV for your preset.
  3. Tick Overwrite products with matching handles if you import a second time, then Upload and preview and Import products.

The sample products have pictures, sizes, packs and specifications filled in, so you can see every feature before you add your own catalog.

#4. Turn on filters

  1. Install the free Search & Discovery app by Shopify if it is not in your admin yet.
  2. Open AppsSearch & DiscoveryFilters and select Add filter.
  3. Add Availability, Price, Product type, Vendor and your variant options such as Length or Size.
  4. Add the metafield filters caliper.drive, caliper.head and, for vehicles, caliper.fitment. Save.

Drive and head type filters appear as drawings automatically. See Filters and search.

#5. Build the menu

  1. Open ContentMenus and edit Main menu.
  2. Add your main collections as top-level items. These become the category bar.
  3. Drag sub-collections under them (indent them). They open in the dropdown tray and the Categories button.

#6. Add the order pad and store pages

  1. Open Online StorePages and select Add page.
  2. Title it Order pad, keep the handle order-pad, and choose the template page.order-pad on the right. Save. The header shows an Order pad link as soon as the page exists.
  3. For pickup counters, add a page with the template page.store-locator, then add your locations in the theme editor.

#7. Check and publish

  1. Open a product page, a collection, the cart and search in the preview, on desktop and on your phone.
  2. If a size does not show on a card, check that the product has a value in caliper.size.
  3. Publish from Online StoreThemes.

Note

Stuck on a step? Search these docs with / or open the support page. You get an automatic confirmation with your request number at once.

Reference

For developers

Caliper is plain Liquid, CSS and JavaScript with no build step and no framework. This page lists the hooks that stay stable between versions, so your changes survive theme updates.

#Where to put your changes

  • Custom CSS in the theme editor: every section has a Custom CSS field (a Shopify feature). Rules there are scoped to that section.
  • Custom Liquid section, and the Custom Liquid block on the product page, for small pieces of markup.
  • Custom section with theme blocks (group, heading, text, button, image, spacer) to build layouts without code.
  • App blocks are accepted on the product page, featured product, custom section, footer, cart page and cart drawer.

Avoid editing base.css or the section files directly: updates replace them.

#Design tokens

Colors, spacing, radii, shadows and motion are CSS custom properties on :root, set from Theme settings. Use them so your additions follow presets and dark mode.

GroupVariables
Surfaces--foam, --foam-raised, --pocket, --photo-ground
Text--ink, --ink-muted, --ink-faint, --ink-raised
Accent and status--accent, --accent-ink, --accent-text, --positive, --warning, --critical
Depth--cut-shadow, --cut-shadow-deep, --raised-shadow, --lift-shadow, --tray-shadow, --lift
Shape--radius-pocket, --radius-control, --radius-xl, --radius-pill
Rhythm--grid-gap, --gutter, --page-width, --space-section
Type--font-heading-family, --font-body-family, --font-mono, --text-s … --text-3xl, --display-1 … --display-3
Motion--dur-1 … --dur-4, --ease-seat, --ease-tray, --ease-out

The <html> element carries state classes you can target: motion-full, motion-subtle, motion-off, density-compact, grid-mobile-1, price-gated, and data-mode="dark" when the shopper picks dark mode.

#Events

EventFired onDetail
search:submitteddocument{ terms } when a search form is sent
cart:updateddocumentafter the cart changes
results:updateddocumentafter filters or sorting re-render a collection
taxview:changeddocumentwhen the shopper switches prices with or without tax
saved:changeddocumentwhen a saved parts list changes
variant:changeddocument{ variantId } after the shopper picks another variant

Example, sending searches to your own analytics:

document.addEventListener('search:submitted', (event) => {
  window.dataLayer?.push({ event: 'site_search', terms: event.detail.terms });
});

#Custom elements

The interactive parts are custom elements that set themselves up when they enter the page, so markup re-rendered by Shopify's Section Rendering API keeps working. Among them: predictive-search, product-info, media-gallery, cart-items, cart-tools, free-shipping, dispatch-promise, bought-together, hot-spots, table-sort, unit-toggle, lite-video, ambient-video.

#Metafields

All theme metafields use the caliper namespace. The full list, with types, is on Product data. A few you may read in your own code:

  • caliper.specs: multi-line text, one Label: value per line
  • caliper.alt_part_numbers: list of replaced or equivalent part numbers
  • caliper.install_steps and caliper.install_time: installation steps, one per line, and the time a job takes
  • caliper.certifications: list of certifications written out (UL listed, CE, RoHS)
  • caliper.code_color (collection): the category's color code

#Templates

Alternate templates you can assign to a product, collection or page: product.kit (contents first), product.technical (specifications and documents first), product.quick-order (every size in one table), collection.finder (finder and filters above a wide grid), page.trade (trade account application), page.order-pad, page.store-locator, page.brands, page.motion.

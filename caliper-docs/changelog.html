Release notes

#Our update promise

  • Your settings stay. Setting and section IDs never change between versions. When a setting is replaced, the old value is read until you save a new one.
  • Every change is listed. Each release lists what is new, what changed and anything you need to do.
  • Nothing is removed silently. A setting or section is only removed in a major version, announced one version earlier.
  • Code edits are yours. Updates replace theme files, so keep changes in settings, custom Liquid blocks and app blocks where possible.
  • Checked before every release. A script compares every setting ID a store may have saved (theme, sections and blocks) with the previous release and stops the release if one would be dropped or change type. Visual baselines of 17 pages at five screen widths are compared too.
  • No paid updater. Updates come through the Shopify theme library at no cost; there are no paid add-ons, locked sections or "pro" versions.

#1.0.0

First public release.

  • Three presets: Vernier, Redline (dark) and Anvil.
  • Part number and barcode search with grouped results, voice search and a phone scanner.
  • Size-led product cards with second image on hover, vendor, save to list, compare and quick add.
  • Collection filters as a sidebar, top row or drawer, price slider, spec finder, load more or infinite scroll, promo tiles.
  • Product page with gallery layouts, variant cards with price and stock, volume prices, feature scores, stock bar, size chart, questions and answers, install video, documents, compatibility check with My garage and pre-order.
  • Cart drawer with added notice, undo, option change, terms box, saved lists, quote request and express checkout buttons.
  • Order pad with CSV upload, barcode scan and shared lists; quick order table with CSV export; reorder.
  • Home sections: part search, category drawers, slideshow, deals with countdown, video, hotspots, collection tabs, stats, FAQ, contact and map, collection carousel and more.
  • Newsletter pop-up, promotion tab, age check and store locator.
  • Brand strip and A to Z brand directory, before and after slider, collection banner video.
  • Gift wrapping, VAT display switch, share and print spec sheet, document preview.
  • Custom section built from blocks (groups that nest, headings, text, buttons, images, spacers, app blocks), and a project gallery section.
  • Top and bottom spacing and a color scheme (page, dark, accent, raised) on every content section.
  • Product card settings for size, pack, first volume price, rating and swatches; cards with options show the spread of sizes.
  • Part number search that ignores dashes and spaces, finds numbers typed without them and notes replaced part numbers; sizes typed as one word ("m6x25") find the same parts as "M6 × 25".
  • Key features block on the product page, connectable to product metafields.
  • Trade setting: prices for signed-in customers only, optionally by customer tag.
  • Optional light and dark mode button for the light presets.
  • Category tiles with the first category large, and brands plus a part number shortcut in the mega menu.
  • Cart page: download as CSV, copy a cart link, purchase order number and delivery instructions.
  • Product page: installation steps, certifications, pins on photos, a millimetre and inch switch, previous and next product, and kit and technical templates.
  • Table view headings sort by product, size, stock or price; empty filter results offer to drop one filter; A to Z index for long category lists.
  • Search: part number matches listed above the results, recently browsed categories, results announced to screen readers.
  • Shop by job, trade account application (page.trade) and an editor-only setup checklist.
  • Card styles (standard, compact, feature), a centered logo option, saved searches, a quantity field in the search panel and a payment terms block.
  • Density setting, one product per row on phones, holidays for the dispatch promise, ambient muted video.
  • Right-to-left language support.
  • English, French, German, Italian and Spanish.
